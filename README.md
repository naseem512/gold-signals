# Gold Signals (XAUUSD 1H)

An installable web app (PWA) that shows gold trend, BUY/SELL/WAIT, SL/TP, lot size and a backtest.

- Signal: EMA9/21 crossover in the EMA50/200 trend direction, with an RSI filter
- Fake-signal filter: 4H trend agrees, strong signal candle, and price within 1 ATR of EMA21
- Data: Binance PAXG/USDT (no key needed), or TwelveData XAU/USD (needs a free API key)

This is not financial advice. Signals can be wrong, so always use a stop loss.
